## The brief

I wanted my site built the way I'd want a client's: the basics tested first, then the design.

<Callout>Every change is checked automatically before it can reach the live site.</Callout>

I wrote down what the site had to do first. Then I built it with AI coding tools in small steps,
each one tested and reviewed before it went in.

## Key decisions

**One source for the CV.** The pop-up and the PDF both come from the same content, and a test fails if
the PDF falls behind the words.

**No cookies.** The site doesn't need them, so it doesn't set any, and there's no banner in your way.

**Write the floors down first.** Speed, security and accessibility each have a minimum score, and a
change that falls below one can't go live.

## Where it is now

It's live, and I'm still adding to it. It's the site you're reading right now.
