## The problem

A pensions administrator wanted to move to automation-driven service delivery. Before anything could
be automated, it needed a clear picture of how its processes ran today and how they should run in
future.

## What I did

I ran as-is assessments of the business processes with the administrator's teams, then defined the
future-state operating model.

I wrote the detailed SOPs and the technical documentation the automation work would build on, so
that handover and training could run the same way each time.

## The outcome

The administrator has its processes assessed, a future-state operating model defined, and the SOPs
and documentation in place to build automation on.
